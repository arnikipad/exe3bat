# exe3bat

Massive menu-driven Python utility for Windows and other Python-capable systems.

## v2.0 features

- System information dashboard
- Environment overview
- Recursive project tree viewer
- SHA-256 file inventory
- Local project backup creator
- JSON diagnostic report generator
- Python validation
- Safe local command runner
- Windows `.bat` launcher generator
- Activity logging to `exe3bat.log`

## Run

```text
py -3 exe3bat.py
```

Or on Windows:

```text
run-exe3bat.bat
```

## Safety

This project is designed as a development/diagnostic utility. It deliberately does not disable Windows security protections, erase disks, overwrite boot records, or silently delete user data.
